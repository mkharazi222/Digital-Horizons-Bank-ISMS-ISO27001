# Digital-Horizons-Bank-ISMS-ISO27001
# 🏦 تطبيق نظام إدارة أمن المعلومات (ISMS) - بنك الآفاق الرقمية
### وفق المواصفة القياسية الدولية ISO/IEC 27001:2022

## 📌 نبذة عن المشروع
مشروع محاكاة وبناء نظام متكامل لإدارة أمن المعلومات (ISMS) لبنك **"الآفاق الرقمية"**، متوافق مع متطلبات البنك المركزي السعودي (SAMA) والهيئة الوطنية للأمن السيبراني (NCA).

---

## 👥 فريق العمل والأدوار
1. **الطالبة 1:** مسؤولة التأسيس، السياق، والنطاق (Governance & Scope Lead).
2. **الطالبة ملاك:** مسؤولة الأصول والضوابط الأساسية (Assets & Baselines Lead).
3. **الطالبة 3:** مسؤولة إدارة المخاطر وبيان القابلية (Risk Management & SoA Lead).
4. **الطالبة زينب:** مسؤولة العمليات، التدقيق، والاستمرارية (Operations & Audit Lead).

---

## 📁 هيكل التسليمات المعتمدة (15 وثيقة)
- **01-Context-and-Governance:** وثيقة النطاق، السياسة العليا، وقائمة الأهداف.
- **02-Assets-and-Baselines:** سجل جرد الأصول المصرفية، سياسة AUP، وضوابط التهيئة.
- **03-Risk-Management-and-SoA:** أداة تقييم المخاطر، وثيقة SoA، المنهجية، والتقرير التنفيذي.
- **04-Operations-and-Business-Continuity:** إجراء الحوادث، أدلة تشغيل IT، وخطة BCP/DRP.
- **05-Evaluation-Audit-and-Improvement:** تقارير التدقيق الداخلي والأداء، وتقرير التدقيق الخارجي.
